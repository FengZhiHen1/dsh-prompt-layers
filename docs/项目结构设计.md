# 项目结构

包名和目录为 dsh-prompt-layers，Host 行 id 为 prompt-layers，配置根为 DSH_HOME/prompt-layers。Git 子仓库历史保留，远端沿用真实存在的旧仓库地址。

| 模块 | 职责 |
| --- | --- |
| index.js | Host 插件导出 |
| src/core/configuration.js | 严格 YAML 与发布 Schema 校验、安全内容路径形状 |
| src/core/layers.js | 精确匹配、字段合并、身份条件、稳定锚定排序 |
| src/core/section-editor.js | 编辑范围校验、保留禁用段的继承工作区及来源快照 |
| src/adapter/files.js | 文件发现、UTF8、安全读写、修订、派生文件 |
| src/adapter/runtime.js | 不可变快照、整体回退、有界结构观察 |
| src/adapter/application.js | 同源编辑、模板显式导入与预览 |
| src/adapter/host.js | 服务/事件/API/轮询生命周期接线 |
| client.js | 插件详情页 UI：SettingsForm 形态的草稿与一次提交 |
| templates/ | 七份批准正文、版本索引、Agent 装配指南 |
| locale/ | 插件管理器显示文案：en/zh 的标题与简介 |
| prompt-layers.schema.json | 用户配置结构权威 |
| test/ | 纯内核、文件、状态及真实运行时契约测试 |

依赖方向为 adapter → core；core 不依赖 Cordis 或 @deepseek-ai 包。客户端从宿主取 React，不创建第二应用或服务。generated 是配置目录里的派生输出，不作为源码或配置输入。

旧 src/core/routes.js、单段常量及旧接口测试和一次性 verify 探针已从当前实现移除，可从 Git 历史恢复。历史 decisions 保留原文；当前机制只由 technical-details 定义。
