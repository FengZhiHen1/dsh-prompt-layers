# 技术栈与兼容性

使用 Node ESM，无编译步骤；测试采用 node:test。Host Config 使用 Schemastery，YAML 使用 yaml 2.x，发布的 Draft 2020-12 Schema 使用 Ajv 8.x。客户端使用宿主 React 和 lazy module loader，不加载 Harness Client 包。

目标基线为 DSH 0.2.1-rc.2 / 687f282e，兼容已验证的上一代 0.2.0-rc.2 / 639ed015。插件只消费 Cordis 注入的服务，未导入其服务定义，不安装额外 Cordis 副本。两代契约断言的差异仅行号，接口形态与执行顺序一致。

`package.json` 声明 `engines.dsh` 为 `>=0.2.0-rc.2 <0.3.0-0`：宿主预检按 `includePrerelease` 求值，该区间覆盖两个 0.2 代预发布，排除 0.1.7 与 0.3 预发布。未声明 DSH peer 依赖，因此 `engines.dsh` 单独决定兼容判定。扩展兼容代际时同步改此区间与 `test/runtime-v1.test.mjs` 的接受列表。

关键接口由目标实例 Inspect 核对：systemPrompt.assemble、system-prompt/assemble waterfall、tools.get(name, scope)、agentPresets.composedPreset/list/acquireScope、connection.fetch.register、session/event，以及 Client plugins.bundle.config、slots 与 locale。

## 阻断模型层的事实

源码 packages/core/agent-loop/src/agent.ts:407 在 prepareRequest 前执行 renderPrompt；:594 进入 agent/request，:604 才 prepareCall（0.2.0-rc.2 为 :405/:576/:587）。已渲染文本不会因最终模型路由或 retry 重建。agent/request 返回 CallConfig，接口明文禁止修改 messages。没有受支持的 post-route 重组接口。

因此不通过私有字段、函数劫持或 user-role 补丁实现模型规则。provider/model 配置可解析合成预览，但当前适配器阻断其候选激活。若未来宿主增加正式接口，需要重新验证晚改路由、重试、主子不同模型及压缩后恢复，再放开门禁。

## 保守能力边界

公开 assembly 不含静态/动态注册来源和 complete 标志；既有段均按受管处理，修改要求显式许可。宿主 complete 在 waterfall 后恢复为唯一段，提交观察必须区分 suppressed-or-changed，不承诺绕过。

tools.get 可证明底层 pwsh 工具对该 Agent 可见（含 PTC）；它不能证明任意第三方 shell 后端的实际方言。缺乏可信方言元数据时 PowerShell 条件为 unknown，不注入。未增加 OS/工具名猜测或每次 Shell 探测。

文件适配器仅支持根内受控相对路径，拒绝符号链接，限制文件数与字节数；保存采用修订检查和同目录临时文件替换。Node 的跨平台 rename 无 compare-and-swap，因此外部编辑器在最终检查到 rename 之间仍存在极小竞态窗口；不能宣称多文件事务。
