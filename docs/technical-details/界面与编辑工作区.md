# Section 管理工作区

## 已确认交互

页面主体管理 Section 与适用范围，顶部选择全局、供应商或精确模型。列表显示所选范围的继承结果，每个 ID 一行；不以文件和模板作为主导航。

全局只显示全局定义；供应商包含全局继承与供应商增量；模型包含 global→provider→model 链。禁用段仍可见，原生段放在独立折叠区，来源于最近观察到的 Agent，不把这一样本视为所有 Agent 的完整清单。

行内展示名称、摘要、启用状态及来源。点击原位展开正文，保留范围选择与其他行；长正文可在原生 dialog 放大编辑，Escape 关闭。模板是显式新增入口，原文编辑置于高级折叠区，状态哈希和观察置于诊断详情。

继承段提供“在当前范围覆盖”和“编辑来源”；前者在当前 YAML 建立独立定义，不回写下层共享 Markdown。已有覆盖可移除并恢复继承。编辑来源明确显示实际保存范围；完成后仍返回当前查看范围。

正文、启停、位置、Agent/Preset/工具条件集中在编辑区。受管原生段必须显式允许覆盖。保存前提供当前/拟保存正文对照，各层定义可按需展开查看。

## 同源写入

workspace 返回每段的有效字段、来源和继承链。section-save 与 section-remove 使用整套候选 revision 拒绝陈旧写入；最终文件写入仍使用文件 revision，所有写操作共享应用串行闸门。原 YAML 通过文档 AST 修改目标段，保留其他段和周边注释；不创建第二份可编辑数据库。

修改继承正文采用当前层内联 content，不修改原 contentFile。when: {} 明确清除继承条件，未声明 when 则继续继承；编辑器选择全部 Agent 且未限制工具时写入空条件。移除覆盖只删除当前层声明；被其他层引用的 Markdown 不删除。候选校验和现有热重载/回退机制继续适用。

## 样式与验收边界

沿用 DSH 原生 settings-form 与 Button 的字段几何、圆角 token、细分隔线及交互状态；不用大框包住每个分组，不重复插件详情页标题。plain-JS 部分只依赖宿主 React 和公开 Cordis 服务，不动态导入 Harness Client 组件包。

UI 不由子代理继续开发或评审；页面实际操作及视觉走查由用户执行。自动检查覆盖渲染空态、坏 YAML 原文修复、离线重试和范围继承写入，不能替代用户实际页面验收。
