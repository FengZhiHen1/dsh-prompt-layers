# Section 管理工作区

## 已确认交互

页面主体管理 Section 与适用范围，顶部"适用范围"字段选择全局、供应商或精确模型。范围字段下方常驻操作说明：本页的新增、编辑、删除和模板添加都写入当前范围；要限定模型，先选“模型”并选择 provider/model，再新建或添加模板；模板添加只使用当前范围，不提供模型选择。滚动到 Section 区后，Sections 标题和展开的 Section 顶部重复显示当前范围，并提供"查看范围设置"回到顶部选择器。切换范围时若存在草稿，先就地确认“切换会丢弃当前草稿”，确认后才丢弃并重新读取；取消则保留草稿与原范围。页面注册在 `plugins.row.config`（key `dsh-prompt-layers#prompt-layers`）：从 Plugins 页进入"提示词分层"详情先看到插件描述与 `prompt-layers` 行，点击该行的 Configure 才进入本工作区；页面外壳、标题、面包屑、描述与 summary 回退由 Plugin Manager 绘制，插件只提供 `page` 与 `summary`。列表显示所选范围的继承结果，每个 ID 一行；不以文件和模板作为主导航。

全局只显示全局定义；供应商包含全局继承与供应商增量；模型包含 global→provider→model 链。禁用段仍可见，原生段同样按行列出。来源于最近观察到的 Agent，不把这一样本视为所有 Agent 的完整清单。

页面采用 DSH 官方 `SettingsForm` 形态：只读/不可用提示、字段区、失败文案与保存键都在同一表单内；保存键在 `!dirty || invalid || saving` 时禁用，成功不额外播报，失败保留草稿。离开页面或确认切换适用范围后丢弃暂存改动；切换前有草稿会先就地确认，没有页面级"放弃"控件，也没有未保存徽标；行级"放弃新增"只丢弃尚未保存的新行，不写文件。

行内展示名称、摘要、来源与草稿状态，展开区顶部显示当前范围与切换入口；可删除/移除的行在行右侧有一个 28px 垃圾桶图标（不占正文编辑区），其 title/aria-label 按状态给出"放弃新增""删除此 Section"或"移除当前覆盖，恢复继承"。点击行主体原位展开编辑区，保留范围选择与其他行；新增行展开编辑正文与 ID。状态哈希与观察置于诊断折叠区。

模板是独立弹层中的逐条新增入口：打开后每行“添加”即作为当前范围的新 Section 加入草稿，行内变为“已添加”，弹层保持打开以便继续添加。为避免误加范围，每行显示“加入：当前范围”；推荐模型层的模板在更宽范围下，第一次点“添加”先在该行展开确认（取消／设置模型范围／仍然添加），确认后才写入，仍不弹出模型选择。弹层顶部同时给出操作顺序：关闭弹层→顶部选“模型”→选 provider/model→重新打开模板弹层。已存在或已继承的模板显示“已添加”/“继承层已有”且不再提供添加；重复点击由草稿按 sectionId 去重。已添加的 Section 若正文与当前模板不同，标签显示“已添加 · 与当前模板不同”（warning），预览展示当前正文→模板正文的逐行 diff 和“用模板正文替换当前正文”的显式确认；替换只改正文，不改 ID、条件、启停和位置，仍由页面保存写入。该比较是当前模板与当前正文的对比，不记录导入版本，不能区分用户编辑与模板升级。模板列表与正文由 Host 启动时读取；改 `templates/` 源文件后需重启 Host 才更新比较，已导入正文仍是独立副本。弹层标题与说明按当前界面语言显示 `title`/`titleZh` 与 `description`/`descriptionEn`，正文预览保持批准的英文原文，不随界面语言翻译。“查看正文”进入只读预览（Section ID、版本、标签与正文），可返回列表；预览不写文件。推荐模型层的模板出现在更宽范围时显示警告但允许添加，不自动切换当前范围（切换会丢弃草稿）；警告旁提供“设置模型范围”按钮，关闭弹层并聚焦顶部范围选择器，由用户自行切换。由这类模板生成的 Section 展开后，在范围标签下持续显示“推荐模型层”警告，说明当前范围、保存后的影响、切换并重新添加的步骤，以及已保存的全局 Section 不会自动迁移；避免保存后才暴露范围过宽。PowerShell 模板的“需 PowerShell”标签在能力不可证明时显示“需 PowerShell（条件不会匹配）”，悬停提示宿主无法证明实际 shell 方言、导入后不会自动匹配，并给出在编辑区清除条件或等待宿主能力的路径；能力判定本身不变。关闭弹层不提交，新增行仍由表单保存键统一写入。目录为空时弹层明确显示“没有可用模板”，触发按钮仍可用。

已保存的本地自定义 Section 可删除当前层定义；存在继承层或原生段时移除的是当前覆盖并恢复继承；新增行只能放弃新增。删除/移除在保存时才写入，保存前显示"保存后移除"并可撤销；新增行放弃后直接消失，不写文件。删除动作是行右侧垃圾桶图标，文案按状态区分，不把已保存 Section 称作草稿。各层定义可在行内按需展开查看。

正文、启停、位置、Agent/Preset/工具条件集中在编辑区。受管原生段必须显式允许覆盖，否则保存禁用。

## 一次保存

所有行内改动只进入浏览器草稿。保存键把全部草稿合并成**一次** revision 围栏的 `commit` 请求：Host 载入一次快照、校验 `expectedRevision`、在同一份 YAML 文档 AST 上依次应用每个 Section 的 save/remove，最后只写一次文件并只热重载一次。任一改动非法或 revision 过期时整批不写入，草稿保留在原处。展开的 Section 底部另有一个保存键，与页脚保存触发同一次 `commit`，禁用条件完全相同。

workspace 返回每段的有效字段、来源和继承链。`commit` 复用 `section-save`/`section-remove` 的字段白名单与校验，原 YAML 通过文档 AST 修改目标段，保留其他段和周边注释；不创建第二份可编辑数据库。

修改继承正文采用当前层内联 content，不修改原 contentFile。when: {} 明确清除继承条件，未声明 when 则继续继承；编辑器选择全部 Agent 且未限制工具时写入空条件。移除覆盖只删除当前层声明；被其他层引用的 Markdown 不删除。候选校验和现有热重载/回退机制继续适用。

## 样式与验收边界

复制官方 `SettingsForm`、`settings-form/fields` 与 `Tag` 的框架和几何：字段 `padding:12px 0` + `gap:6px`、相邻字段 `0.5px` 分隔线、控件 34px、`--dsw-radius-md`、`bg-layer-3`、13px/1.5、hint 12px/1.5 位于控件下方、保存行 `padding-top:16px`；保存键是官方 `.save`（13px、`padding:5px 14px`、`label-primary` 底、`bg-layer-3` 字），不是 36px 的 Button 原子。页面注册为 `plugins.row.config`，`view:'summary'` 返回简短摘要；页面外壳不在插件内。行删除使用原生 `ModelRow` 的 28px 方形图标按钮（透明底、`label-tertiary`、hover `interactive-bg-hover-danger` + `state-error-primary`、14px 垃圾桶），不使用带文字的"删除草稿"按钮。样式只用 `--dsw-alias-*` 与设计 token，无字面颜色；plain-JS 部分只依赖宿主 React 和公开 Cordis 服务，不 `require` 任何 Harness Client 组件包。

模板选择器采用原生 Modal 几何：最大 640px、`bg-layer-2`、`elevation-prominent`、内容边距 24px、16/24 标题、14/22 说明、footer 36px 主/次按钮；行内标题 14/22 500、说明 13/20 secondary 且两行截断、标签 11/17，添加/预览为 28px 紧凑按钮。弹层用原生 `<dialog>.showModal()` 获得 top layer、Esc 关闭与焦点约束；滚动区可聚焦，明暗主题与滚动条沿用 token。

模板选择器按用户明确指令由子代理重构；页面其余部分和整体视觉评审仍不在子代理自行扩展的范围内。页面实际操作及视觉走查由用户执行。自动检查覆盖空态、草稿校验、单次提交、拒绝后保留草稿、不可用提示、`plugins.row.config` 注册与 summary、保存行/新增行/覆盖行的删除标签、模板空目录、逐条添加、重复抑制、正文差异标签、逐行 diff、确认替换、换行/尾空白归一、范围标签、操作顺序说明、模板加入目标、模型模板添加确认、模型层推荐警告、切换范围确认、模板“设置模型范围”入口、双语标题/说明、正文预览、范围警告、PowerShell 条件标签及其说明、关闭、无 Client 包引用与无字面颜色，不能替代用户实际页面验收。
