# Section 管理工作区

## 已确认交互

页面主体管理 Section 与适用范围，顶部"适用范围"字段选择全局、供应商或精确模型。列表显示所选范围的继承结果，每个 ID 一行；不以文件和模板作为主导航。

全局只显示全局定义；供应商包含全局继承与供应商增量；模型包含 global→provider→model 链。禁用段仍可见，原生段同样按行列出。来源于最近观察到的 Agent，不把这一样本视为所有 Agent 的完整清单。

页面采用 DSH 官方 `SettingsForm` 形态：只读/不可用提示、字段区、失败文案与保存键都在同一表单内；保存键在 `!dirty || invalid || saving` 时禁用，成功不额外播报，失败保留草稿。离开页面或切换适用范围即丢弃暂存改动，没有"放弃"控件，也没有未保存标记。

行内展示名称、摘要、来源与草稿状态。点击原位展开编辑区，保留范围选择与其他行；新增行展开编辑正文与 ID。状态哈希与观察置于诊断折叠区。

模板是独立弹层中的逐条新增入口：打开后每行直接“添加”，立即作为当前范围的新 Section 加入草稿，行内变为“已添加”，弹层保持打开以便继续添加。已存在或已继承的模板显示“已添加”/“继承层已有”且不再提供添加；重复点击由草稿按 sectionId 去重。弹层标题与说明按当前界面语言显示 `title`/`titleZh` 与 `description`/`descriptionEn`，正文预览保持批准的英文原文，不随界面语言翻译。“查看正文”进入只读预览（Section ID、版本、标签与正文），可返回列表；预览不写文件。推荐模型层的模板出现在更宽范围时显示警告但允许添加，不自动切换当前范围（切换会丢弃草稿）。关闭弹层不提交，新增行仍由表单保存键统一写入。目录为空时弹层明确显示“没有可用模板”，触发按钮仍可用。

已有覆盖可移除并恢复继承：移除在保存时才写入，保存前可撤销。各层定义可在行内按需展开查看。

正文、启停、位置、Agent/Preset/工具条件集中在编辑区。受管原生段必须显式允许覆盖，否则保存禁用。

## 一次保存

所有行内改动只进入浏览器草稿。保存键把全部草稿合并成**一次** revision 围栏的 `commit` 请求：Host 载入一次快照、校验 `expectedRevision`、在同一份 YAML 文档 AST 上依次应用每个 Section 的 save/remove，最后只写一次文件并只热重载一次。任一改动非法或 revision 过期时整批不写入，草稿保留在原处。展开的 Section 底部另有一个保存键，与页脚保存触发同一次 `commit`，禁用条件完全相同。

workspace 返回每段的有效字段、来源和继承链。`commit` 复用 `section-save`/`section-remove` 的字段白名单与校验，原 YAML 通过文档 AST 修改目标段，保留其他段和周边注释；不创建第二份可编辑数据库。

修改继承正文采用当前层内联 content，不修改原 contentFile。when: {} 明确清除继承条件，未声明 when 则继续继承；编辑器选择全部 Agent 且未限制工具时写入空条件。移除覆盖只删除当前层声明；被其他层引用的 Markdown 不删除。候选校验和现有热重载/回退机制继续适用。

## 样式与验收边界

复制官方 `SettingsForm`、`settings-form/fields` 与 `Tag` 的框架和几何：字段 `padding:12px 0` + `gap:6px`、相邻字段 `0.5px` 分隔线、控件 34px、`--dsw-radius-md`、`bg-layer-3`、13px/1.5、hint 12px/1.5 位于控件下方、保存行 `padding-top:16px`；保存键是官方 `.save`（13px、`padding:5px 14px`、`label-primary` 底、`bg-layer-3` 字），不是 36px 的 Button 原子。样式只用 `--dsw-alias-*` 与设计 token，无字面颜色；plain-JS 部分只依赖宿主 React 和公开 Cordis 服务，不 `require` 任何 Harness Client 组件包。

模板选择器采用原生 Modal 几何：最大 640px、`bg-layer-2`、`elevation-prominent`、内容边距 24px、16/24 标题、14/22 说明、footer 36px 主/次按钮；行内标题 14/22 500、说明 13/20 secondary 且两行截断、标签 11/17，添加/预览为 28px 紧凑按钮。弹层用原生 `<dialog>.showModal()` 获得 top layer、Esc 关闭与焦点约束；滚动区可聚焦，明暗主题与滚动条沿用 token。

模板选择器按用户明确指令由子代理重构；页面其余部分和整体视觉评审仍不在子代理自行扩展的范围内。页面实际操作及视觉走查由用户执行。自动检查覆盖空态、草稿校验、单次提交、拒绝后保留草稿、不可用提示、模板空目录、逐条添加、重复抑制、双语标题/说明、正文预览、范围警告、关闭、无 Client 包引用与无字面颜色，不能替代用户实际页面验收。
